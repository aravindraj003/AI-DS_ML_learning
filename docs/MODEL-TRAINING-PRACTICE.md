# Model Training Practice

Student-side practice page for online Jupyter Notebook ML training.

External workspace:
https://nextleap.app/online-compiler/jupyter-notebook

Flow:
1. Open Jupyter Notebook from the LMS.
2. Choose Python (Pyodide).
3. Create/select a Python code cell.
4. Paste the sample Iris classification program.
5. Run the cell.
6. Experiment with model settings and compare results.

The LMS does not proxy or execute the notebook. The notebook runs on the external provider.
